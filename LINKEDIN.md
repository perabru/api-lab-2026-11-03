Compartilho uma API para organizar projetos de aulas, portfólio ou laboratório: um catálogo local em Node.js, sem dependências externas.

Ela permite cadastrar, consultar, atualizar e excluir projetos, buscar por nome e descrição, filtrar por etiquetas e navegar pelos resultados com paginação. Os registros ficam em arquivo e continuam disponíveis após reiniciar o servidor.

A referência para o desenho da paginação foi a documentação da API REST do GitHub. Um aprendizado que o projeto demonstra é como preservar os filtros nos links para a próxima página e definir uma ordenação com desempate, evitando resultados imprevisíveis em um catálogo estático.

A entrega inclui 11 testes de integração aprovados, documentação em português e uma demonstração que pode ser executada sem alterar os dados do catálogo. É um projeto para estudo e execução local, com os limites documentados no README.
